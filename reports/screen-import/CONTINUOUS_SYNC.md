# 화면 적용과 연속 착수 갱신 개선

## 변경

- 화면 공유 중 검토·적용하면 감시를 바로 시작한다. 정지 이미지는 적용만 한다.
- 별도 시작 버튼을 없애고 일시정지·감시 재개 버튼 하나를 사용한다.
- 영상 확인 간격을 250ms에서 60ms로 줄였다. 처리 중인 프레임이 있으면 큐를 쌓지 않고 다음 확인 때 최신 영상을 읽는다.
- 말·벽·차례 인식은 전용 Web Worker에서 처리한다. 일시정지·재보정 시 이전 작업을 종료하고 세대 번호로 늦은 결과를 차단한다. 작업이 3초를 넘으면 재생성한다.
- 외부 차례 근거와 유일한 합법 진행이 일치하는 1~2수는 같은 배치 3회를 기다리지 않고 반영한다. 그 밖의 경우는 2회 확인한다. 격자 이동, 불법 배치, 상충하는 차례, 모호한 누락 진행은 계속 보류한다.
- 보드 갱신은 AI 분석 완료를 기다리지 않는다. 기존 취소·세대 검증을 유지한다.

## 검증

- Node 테스트 144개 통과.
- 격리된 Chrome에서 합성 MediaStream으로 화면 가져오기·인식·자동 감시 및 즉시압박 엔진 연결 검증 45개 통과. 화면 연동·관전·AI 대전에서 실제 즉시압박 Native 서비스의 추천 결과를 확인했다.
- 120ms 간격 16수 연속 영상에서 진행 중 갱신과 마지막 16수 반영 확인. 각 착수 직전 수집한 상태는 `continuous-stream.json`에 보관한다.
- 실제 Wallz 탭 공유는 이 자동 검증에 포함되지 않는다. 브라우저가 전달하지 않은 중간 프레임이나 유일하게 복원할 수 없는 기보까지 보장하지 않는다.

## 남은 추천 순서

1. 실제 공유 영상의 인식·격자 탐지·반영 시간을 측정하고 고해상도·저사양 환경을 점검한다.
2. 전체 격자 재탐지도 Worker로 옮기고, 보드 변화 영역만 읽어 처리량을 더 줄인다.
3. 빠른 연속 벽 설치·점프·애니메이션·가림을 섞은 장시간 회귀 영상을 추가한다.
4. 즉시압박 엔진의 구버전 실행기 재사용·서비스 연결 상태를 진단하고 필요하면 재시작 안내를 명확히 한다.

이번 변경은 AI 평가 함수나 기본 엔진 승격을 포함하지 않는다.
