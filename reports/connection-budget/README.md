# 연결 벽 위험 평가와 가변 계산 예산

Atlas 0.4 보완 빌드. 5.3 원본과 엔진 선택 두 가지는 유지한다. 서비스의 보완 설명과 빌드 해시로 실제 적용 여부를 구분한다.

## 연결 공격

상대 벽이 2개 이상이면 `상대 첫 벽 → 내 합법 대응 → 상대 연결 벽`을 제한 탐색한다. 내 대응 없이 상대 벽 두 개를 연속 설치하지 않는다.

- 첫 벽은 합법 경로와 거리 손실·기존 벽 연결을 기준으로 최대 2개를 선택한다. 상대에게 이득이 없고 기존 연결도 없는 준비 벽은 놓칠 수 있다.
- 모든 합법 말 대응과 첫 벽 주변의 방어벽 최대 3개를 확인한다. diagnostics의 replyLimit는 방어벽 후보 제한이다. 각 방어 이후 연결 벽은 최대 3개다.
- 연결 벽은 첫 벽과 실제 선분을 접하는 후보이며, 불법 교차·겹침·양쪽 경로 차단을 제외한다.
- 공격자는 경로 손실을 크게 만드는 후속 벽을, 방어자는 그 손실을 작게 만드는 대응을 선택한다. 거리 차 변화에 양측의 소비 턴 차이를 보정한다. 최대 6의 휴리스틱 위험값이며 승률·정확한 도착 턴·강제 패배 증명이 아니다.
- 내 합법 말 이동과 유망한 벽 2개를 추가로 살펴, 루트 기준 위험 대비 변화에 48점을 곱해 기존 수 평가에 반영한다. 변화량은 ±192점으로 제한한다. 미검토 행동은 기준 추정으로 남기며 안전 보너스를 만들지 않는다.
- 추가 계산은 남은 시간의 14%와 60ms 중 작은 값 이내다. 완료하지 못하면 부분 점수는 버리고 기존 평가를 사용한다. 완료 표시는 제한 후보의 계산 완료를 뜻하며 전체 공격·방어를 조사했다는 뜻이 아니다.
- 기존 메이트 점수 보호·즉시 승리·완전 탐색 승리 전략 처리를 유지한다. 선택적 공격 생략은 과소평가, 방어 생략은 과대평가를 만들 수 있다.

## 가변 분석

한 번의 최대 15초 검색을 이어가며 완료 깊이 결과를 갱신한다. 처음 확보한 추천을 0.5초 목표로 표시한다. 첫 완료 결과가 늦으면 그보다 늦을 수 있다.

- 위험 추정 2 이상, 남은 방어벽 3 이하, 연속 벽 2회 이상, 골인 3칸 이내, 위험 평가 미완료 또는 선택 수 미검토이면 추가 분석을 유지한다.
- 단순한 경우라도 최소 2초가 지나고, 서로 다른 최근 3개 깊이의 첫 추천이 같아야 조기 종료 후보가 된다.
- 같은 홀짝 깊이 사이 평가 변화는 48점 이하, 세 깊이 전체 평가 범위는 180점 이하여야 한다. 홀짝 깊이의 지평선 효과를 구분하되 전체 점수의 큰 변동은 허용하지 않는다.
- 위 기준은 CPU 절약을 위한 안정 추정일 뿐 안전 증명이 아니다. 같은 추천만 반복된다고 종료하지 않는다. 5.3처럼 위험 자료가 없는 엔진은 이 안정 추정으로 조기 종료하지 않는다.
- 완전 탐색 결과 또는 엔진 자체 종료는 별도로 존중한다. 위험 모드라고 반드시 15초를 채우는 것은 아니다.
- 조기 종료 시 완료된 최신 결과를 확정해 저장한 뒤 진행 검색을 취소한다. 취소 예외가 확정 결과를 지우지 않도록 처리한다. 배치·차례 변경 시 기존 세대와 타이머를 폐기하며, 고정된 표시 추천과 최신 결과의 구분도 유지한다.
- 화면에 빠른 추천·위험 상황 추가 분석·안정 추정 종료와 사유를 표시한다. JSON connectionRisk, analysisBudget, adaptiveStop에 근거를 저장한다.

## 확인과 한계

Rust 릴리스·웹 빌드와 실행 서비스 버전·빌드를 확인한다. 사용자의 기존 요청에 따라 긴 대전·전체 테스트는 생략했다. 네 위치의 짧은 분석과 실제 엔진을 연결한 가변 흐름을 확인했다.

- 최근 기보 23수 직전: 위험 추정 4, 기존 d7 세로벽 추천 유지. 해당 선택 수는 추가 위험 검토 후보 밖이므로 안전하다고 표시하거나 안정 종료하지 않는다.
- 최근 기보 19수 직전: 앞선 보완과 같이 f7 말 이동 추천 유지.
- 시작 배치: 첫 표시 약 0.515초, 안정 추정 종료 약 2.009초, 실제 검색 취소 후 오류 없이 완료. 시간은 해당 실행 관측이며 보장값이 아니다.

위 관측은 실제 대국 승리나 이전 빌드 대비 실력 향상 검증이 아니다. 입력 배치와 출력은 diagnostics.json, 가변 흐름은 variable-opening.json에 보존했다. 다음 검토 대상은 새 기보에서의 위험 누락·과대평가와 후보 제한에 따른 계산 비용이다.
