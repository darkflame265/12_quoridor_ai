# 소스 정리 기록

## 범위

2026-11-06, 공개 배포와 다른 프로젝트 변경을 제외하고 소스 정리 및 브라우저 AI 실행을 진행했습니다. 저장소 공개 상태와 Pages 설정은 변경하지 않았습니다.

- 의존성을 추적해 미사용 연구 스크립트·중간 평가·보고서 등 916개 파일을 제거했습니다. 이 수는 작업 폴더의 생성 보고서를 포함하며 Git 삭제 파일 수와는 다릅니다.
- 빈 임시 파일 `apply(defended`, `f.id`, `x.id`를 삭제했습니다.
- 소스·테스트·로컬 실행 파일 95개를 기능별 폴더로 이동했습니다.
- 구버전 연구 문서는 최종 비교 요약과 외부 구성 요소 고지 위주로 정리했습니다.
- 기존 테스트가 읽는 자료는 `tests/fixtures`로 이동했습니다. 로컬 모델과 Python 엔진 실행 의존성은 보존했습니다.
- `docs/evidence`에는 작은 최종 비교 요약만 보관합니다. 대량의 수순·중간 결과는 현재 트리에서 제거했습니다.
- VS Code에서 생성 폴더를 숨겨 소스 중심으로 탐색할 수 있게 했습니다. 숨김은 삭제와 다릅니다.

## 복구

원래 연구 파일은 Git의 `backup-before-browser-pages-20261106` 태그에서 확인할 수 있습니다. 예:

```sh
git show backup-before-browser-pages-20261106:scripts/compare-sigma-engines.mjs
```

기존 Git 이력을 다시 쓰거나 개인 브라우저의 기보·설정을 삭제하지 않았습니다.
