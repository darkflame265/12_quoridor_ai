# 대기 권장 표시·계산 재개·종반 경주 평가

Atlas 0.4의 보완 빌드다. 선택 목록 0.4·5.3과 기본 가변·화면 연동 설정을 유지한다. 새 버전의 승률 개선으로 해석하지 않는다.

## 대기 표시

보드 바로 위에 첫 추천 준비·대기 권장·지금 착수 가능·추가 대기 실익 낮음(추정)·분석 종료를 표시한다. 최근 추천 변경과 위험 평가 미완료를 고려하며, 최근 세 완료 깊이의 추천 및 같은 홀짝 깊이 평가 안정성을 사용한다. 개선 확률 퍼센트나 더 좋은 수가 나올 정확한 시각을 제시하지 않는다.

추천 안정과 판세는 별도다. 계산 중 최근 추천이 안정적이면 현재 수로 착수할 수 있다고 안내하면서, 말 이동 경주가 열세면 그 사실을 따로 표시한다. 이는 승리 보장 또는 전체 게임의 최선 수 증명이 아니다. 새 결과가 오래 없다는 이유로 대기 실익이 낮다는 표시도 추정이며, 위험 자료가 불완전하면 해당 표시를 하지 않는다.

0.25초 간격으로 현재 분석 경과·최대 잔여 예산·마지막 완료 결과의 나이·완료 깊이와 다음 비교 상태를 갱신한다. 분석 경과는 설정·전송을 포함한 벽시계 시간으로 CPU 사용 시간 측정값이 아니다. 마지막 결과의 elapsedMs와 구분한다. 표시 사유는 최소 3초 이내 다시 갱신한다. 종료 후에는 남은 예산 대신 계산 종료를 표시한다.

추천이 바뀌면 이전 수→새 수를 5초간 강조한다. 같은 배치·차례·엔진의 재분석에서도 마지막으로 실제 표시한 수와 비교한다. 고정한 추천과 최신 결과가 다르면 둘을 별도로 표시한다. 고정 기능은 그대로 유지한다.

## 인식 흔들림

화면 연동이 불확실해지면 즉시 추천·경로를 숨긴다. 기존 가변 분석은 최대 300ms만 유지하고, 그 안에 동일 배치·차례·엔진·세대로 확인되면 경과 시간과 계산을 이어간다. 새 배치가 확인되면 즉시 취소하며, 300ms 이후에도 불확실하면 취소한다. 실제 새 배치에 이전 결과를 적용하지 않는다. 최초 표시의 0.5초 목표도 보존한다.

이 흐름은 새 프레임과 기존 상태가 일치함을 확인하는 기존 화면 인식 검증을 사용한다. 긴 인식 실패·설정 변경·공유 중지·수동 재분석은 계속 취소/재시작할 수 있다. 모든 재시작이 제거된다는 뜻은 아니다.

기보에는 analysis-suspend-display, analysis-resume-display, analysis-cancel의 사유와 세대, 실제 표시 변경, 분석 경과와 대기 안내 상태를 추가한다. action의 analysisContext에는 마지막으로 보인 대기 상태도 남긴다. 새 게임·불러오기·새 배치 적용 시 이전 분석 맥락을 초기화한다.

## 종반 경주

상대 벽이 0개일 때 기존 말 이동 완전 계산 표의 결과를 raceAssessment에 보존한다. 이전에는 제한된 게임에서 승리하는 경우만 표를 활용하고, 패배·무승부 결과는 일반 검색으로 넘어가면서 사용자에게 별도 설명을 주지 않았다.

말 이동만으로 패배하는 경우도 조기에 표시하지만 전체 게임의 패배 확정으로 바꾸지 않는다. 내 벽이 정확히 1개 남았으면 모든 합법 벽의 상대 현재 최단 거리 지연 효과를 최대 12ms/남은 시간 4% 이내에 조사한다. 완료 시 지연 효과가 모두 0이면 루트 일반 평가에 120점의 유한한 열세 보정을 적용한다. 모든 수에 동일한 보정이며 이 보정 자체가 행동의 상대 순위를 개선하는 것은 아니다. 미래 위치의 벽 효용까지 증명하지 못해 과도하게 불리하게 볼 가능성도 있다. 기존 메이트 점수·완전 승리 전략 처리는 유지한다.

시간 초과의 부분 벽 조사로 점수를 보정하지 않는다. 후속 호출이 미완료라고 기존 완료 조사 결과를 덮어쓰지 않는다. 5.3 원본 소스는 변경하지 않는다.

## 확인

Rust 릴리스·웹 빌드, 실제 서비스 버전·빌드·배포 설정을 확인한다. 사용자의 기존 요청에 따라 전체 테스트·긴 대전은 생략했다. 짧은 실제 엔진 흐름과 네 종반 위치를 관측했다. 화면의 시각적 브라우저 검증은 실행하지 않았다.

- 시작 배치: 첫 표시 약 0.512초, 안정 추정 종료 약 2.013초. 표시된 마지막 완료 결과는 0.428초 시점의 결과여서 경과 시간과 구분되는 것을 확인했다.
- 51수 직전: 말 이동 한정 패배·남은 벽의 현재 지연 효과 0을 표시한다. 약 2초 이후 추천 안정 상태에서 착수 가능 안내를 하며 열세 판세는 따로 유지한다. 2.5초에 수동 취소한 흐름에서 오류가 없었다.
- 41수 직전: 일반 검색 +11과 별개로 말 이동 경주는 패배라는 정보가 나온다. 벽이 2개 남아 단일 벽 보정은 하지 않는다.
- 51수 직전 새 프로세스 500ms 비교에서 일반 평가 -132→-252, 행동 c2는 그대로였다. 깊이가 달라진 위치는 원시 점수를 직접 비교해 개선으로 주장하지 않는다.
- 57수 직전 메이트 예상 점수 -29992는 동일하게 유지됐다. 모든 조사 수는 합법이었다.

flow-diagnostics.json과 race-diagnostics.json에 입력·결과를 보존한다. 같은 배치의 짧은 불확실성 재개는 코드 경로를 검토했으며 실제 화면을 통한 반복 관측은 별도 과제다. 다음 검토 대상은 실전의 대기 안내 적절성·추천 변경 알림 누락·재시작 사유와 장거리 미로의 실제 대응 개선이다.
