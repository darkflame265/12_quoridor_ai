# 게임 화면 자동 연동과 내 차례 추천

2026-10-29. 수동 프레임 가져오기 다음 단계로 연속 영상 감시를 추가했습니다. 게임 화면 공유가 유지되면 가져오기 창을 닫아도 왼쪽 메인 보드가 자동 갱신됩니다. 오른쪽 게임의 클릭은 사용자가 직접 합니다. AI 알고리즘·모델·기본 엔진은 변경하지 않았습니다.

## 사용 순서

1. 앱을 새로고침하고 **모드 → 화면 연동 · 자동 감시**를 선택합니다.
2. **오른쪽 게임 화면 연결**에서 실제 게임 탭/창을 선택합니다. 정지 이미지 파일만 가져오면 자동 감시를 시작할 수 없습니다.
3. **현재 프레임 고정** 후 숫자·테두리를 제외한 9×9 보드 영역을 드래그합니다. 격자와 칸이 맞도록 간격을 조정합니다.
4. **선택 영역 인식** 후 말·벽·원본 아래쪽 출발 진영·현재 차례·잔여 벽을 대조합니다. 내 진영도 메인 플레이 설정에서 맞춰 주세요.
5. **확인한 배치를 왼쪽에 적용**합니다. 가져오기 창이 닫힙니다.
6. 메인 화면의 **자동 감시 시작**을 누릅니다. 이후 오른쪽에서 두면 왼쪽 메인 보드·기보·차례·벽 수가 갱신됩니다. 매번 프레임을 고정하거나 적용할 필요가 없습니다.
7. **내 차례에 최선 수 자동 분석**은 기본 켜짐입니다. 원본 변화가 확인되는 즉시 이전 추천과 계산을 취소하고, 새 배치가 확정된 후 내 차례에만 다시 분석합니다. 분석 시간·코어·엔진은 기존 플레이 설정을 사용합니다.
8. **일시정지**는 공유를 유지하고 감시·자동 분석만 멈춥니다. 다시 시작하면 놓친 한두 수를 복원합니다. **공유 중지**는 캡처 트랙도 종료합니다.

가져오기 창의 큰 원본 그림과 보정 보드는 영역 지정용 고정 프레임입니다. 자동 갱신 대상은 메인 게임 보드입니다. 감시 중 검토 창을 다시 열면 감시를 일시정지하고 현재 프레임을 고정합니다. 다시 인식·적용한 뒤 감시를 시작하세요.

## 반영 기준과 복구

- 약 250ms마다 새 영상 프레임을 읽고 동일한 말·벽 배치가 연속 3회 나올 때 반영합니다. 일반적인 확인 지연은 약 0.5~0.75초에 브라우저 지연과 AI 분석 시간이 더해집니다. 백그라운드 탭에서는 타이머가 늦어질 수 있습니다.
- 이전 상태에서 **합법적인 한 수 또는 두 수**로 유일하게 연결되는 경우만 반영합니다. 직선/대각 점프, 말과 벽의 혼합, 양쪽의 빠른 두 수를 처리합니다. 차례는 초기 수동 확인값에서 교대하고 잔여 벽은 설치 이력으로 계산합니다. 차례 표시·숫자를 OCR로 읽지는 않습니다.
- 모든 설치 벽의 소유 색상, 겹침·교차, 목표 경로, 잔여 수를 검사합니다. 벽 목록 순서만 달라지는 것은 변화로 보지 않습니다.
- 말 후보 누락, 불가능한 이동, 벽 삭제·색 변경, 두 수를 넘긴 변화는 마지막 정상 보드를 유지하고 이유를 표시합니다. 안정된 정상 배치가 돌아오면 감시·분석을 재개합니다. 인식이 불확실한 동안 수동 분석도 막습니다.
- 새 게임·되돌리기는 자동 복원하지 않습니다. **화면 연결 · 이미지 인식**을 열어 현재 프레임을 인식·확인·적용하고 감시를 다시 시작하세요. 초기 차례가 틀렸을 때도 같은 방법으로 고칩니다.
- 공유 영상 크기가 바뀌면 감시를 중지하고 영역 재지정을 요구합니다. 같은 영상 크기 안에서 보드 위치나 브라우저 확대만 바뀌는 경우도 직접 영역을 다시 지정해야 합니다.
- 새 프레임이 3초 이상 오지 않으면 이전 추천을 지웁니다. 공유 종료·다른 모드 전환·페이지 종료는 감시 타이머와 트랙을 정리합니다. 새로고침 후 공유 권한과 감시는 자동 재개하지 않습니다.
- 화면 모드에서는 메인 보드를 직접 조작하거나 기보를 무를 수 없습니다. 양쪽 직접 조작으로 전환하면 가져온 배치를 시뮬레이션할 수 있으며, 화면 연동으로 돌아올 때 원본을 다시 확인해야 합니다.

## 인식 제한

현재 어두운 보드의 청록·분홍 단색/링 말과 색 벽을 대상으로 합니다. 작은 이동 점, 회색 미리보기, 짧은 애니메이션은 형태·색상·연속 프레임 검사로 걸러냅니다. **실제 벽과 같은 색·형태의 미리보기가 충분히 오래 유지되면 영상만으로 구분하지 못할 수 있습니다.** 착수 후 원본 보드 밖으로 커서를 옮겨 주세요. 이 한계를 차례·벽 수의 독립 판독과 실전 영상 검증으로 보완하는 것이 다음 우선순위입니다.

이미지 처리와 인식은 브라우저 안에서 수행합니다. 캡처 이미지를 저장·업로드하지 않고, 저장 기보에는 확인한 최초 배치와 이후 추적한 수만 담습니다. 실제 이전 대국 기록을 만들어 넣지 않습니다.

## 검증

- 전체 Node 테스트 **113개 통과**. 한두 수 추론, 점프, 벽 소유·잔여 수, 종료 수, 차례 불일치·순간이동·벽 삭제·과도한 수 변화 차단, 연속 프레임 안정화와 기존 저장 호환성을 검사했습니다.
- 웹 빌드 통과. 독립 headless Chrome에서 **15개 브라우저 시나리오 통과**, 처리되지 않은 페이지 오류 0개.
- 닫힌 가져오기 창 뒤에서 영상 갱신→실제 픽셀 인식→한두 수 반영→자기 차례 추천까지 확인했습니다. 일시정지·재개, 자동 분석 켜기/끄기, 불가능한 배치 보류·복구, 영상 정지·복구, 공유 크기 변경, 공유 종료·거절·늦은 권한 응답 정리도 검사했습니다.
- 브라우저의 공유 영상은 자체 캔버스 **합성 MediaStream**입니다. 실제 Wallz 화면 공유와 실전 장기 대국 정확도는 아직 검증하지 않았습니다. QA의 분석은 Atlas 3으로 실행했습니다.

## 남은 추천 우선순위

1. **실제 게임 영상 검증**: 다양한 벽·점프·빠른 착수와 실제 공유 환경에서 오인식률·갱신 지연을 측정하고 실패 배치를 회귀 테스트로 추가합니다.
2. **차례·잔여 벽 독립 판독**: 원본 표시와 추적 결과를 대조해 초기 차례 오류와 벽 미리보기 오인식을 줄입니다.
3. **되돌리기·새 게임·놓친 여러 수 복구**: 기보와 알려진 과거 상태를 활용해 수동 재적용 빈도를 낮춥니다.
4. **보드 위치·확대 변경 자동 재보정**: 같은 영상 크기에서 보드만 움직이는 경우도 탐지합니다.
5. **인식 처리 최적화와 표시 개선**: 선택 영역 중심 처리, 실제 지연 표시, 여러 테마·아바타 대응을 진행합니다.
