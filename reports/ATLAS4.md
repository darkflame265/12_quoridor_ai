## 미로 계산량

`atlas4-maze-holdout/report.json`: 수당 150ms, 같은 미로 배치에서 진영 교환, 12국 6승 6패.

정확한 후반 테이블 조회를 제외한 탐색:

| 엔진 | 노드 | 실제 검색 시간 | 평균 완료 깊이 |
|---|---:|---:|---:|
| Rust/WASM | 7,073,419 | 19,198ms | 6.75 |
| Atlas 3 JS | 1,711,588 | 19,413ms | 5.58 |

관측한 초당 노드 처리량은 약 4.18배입니다. 구현과 선택적 탐색 순서가 완전히 같지 않아 이 비율을 순수 언어 벤치마크나 실력 배수로 해석하지 않습니다. 더 깊게 읽는 것만으로 이 미로 표본의 승률이 개선되지는 않았습니다.

## 외부 엔진

원본: https://github.com/gorisanson/quoridor-ai

커밋: `e15d6e7825e6f7c2f3a41de0ecef1af7aa290f1e`, MIT, Copyright (c) 2019 Kyutae Lee.

원본 `game.js`, `ai.js`를 별도 체크아웃에서 읽고 UCT MCTS를 재사용합니다. 소스는 저장소에 복제하지 않습니다. 원본의 규칙으로 전체 기보를 재생하고, 반환한 수는 프로젝트의 독립 규칙 엔진으로 다시 검사합니다. 롤아웃 배치 사이에서 시간 제한을 확인하므로 실제 검색 시간과 초과 여부를 보고서에 기록했습니다.

`atlas4-external-holdout/report.json`은 표준 시작, 레이스, 혼합, 미로 배치에서 진영을 교환한 8국을 포함합니다. 결과는 8승 0패이며, 이 외부 엔진의 해당 설정에 대한 결과일 뿐 모든 인간·모든 엔진보다 강하다는 증거는 아닙니다. 보고된 탐색량은 Rust의 트리 노드와 외부 엔진의 롤아웃으로 단위가 달라 직접 비교하지 않습니다.

## 실제 초기 학습

- 최초: 자가대국 2판, 71개 학습 상태.
- 첫 재개: 자가대국 8판을 두 회차로 실행, 364개 상태 추가. 회차별 Rust 기준 엔진 성적 0승 4패, 1승 3패.
- 두 번째 재개 및 과거 모델 리그: 2판, 77개 상태 추가. Rust 기준 엔진에 0승 2패.
- 합계 12판, 512개 상태. 최종 회차 4 체크포인트와 가중치를 보존.
- 학습 손실은 회차 1의 6.19에서 회차 3의 4.82로 줄었으나 상대 실력 우위를 의미하지 않음.
- `models/registry.json`: 활성 신경망 모델 없음. 실험 가중치를 기본 엔진으로 승격하지 않음.

보고서와 자가대국은 `training-initial`, `training-resumed`, `training-league` 폴더에 있습니다. 일반 실행 디렉터리는 Git에서 제외하고 `models/bootstrap-checkpoint.pt` 하나를 포함해 다른 PC에서도 재개할 수 있도록 했습니다. 아직 학습량은 매우 작으며 이 단계로 초인적 실력에 도달했다고 볼 수 없습니다.

## 확인한 항목

- Node 테스트 40개, Python 테스트 3개, Rust 테스트 3개 통과.
- Vite 배포용 빌드 성공. WASM 산출물 약 219KB 포함.
- WASM의 무작위 진행·미로 합법 수, 경로 길이, 전략 점수, 전술 문제 대조.
- 모델 정규화와 정책 행동 인덱스, PyTorch·JS 추론 값 대조.
- 실제 Worker 계산과 취소·다음 작업 간 분리.

이 문서는 통과한 테스트와 실제 실행 결과를 기록하며, 대규모 학습 완료나 인간 불패를 보장하지 않습니다.
