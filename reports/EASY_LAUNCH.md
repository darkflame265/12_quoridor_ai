# 바탕화면에서 쿼리도 실행

바탕화면에 다음 바로가기를 설치했습니다.

- **Quoridor AI**: 더블클릭하면 게임 화면과 AI 엔진을 자동 준비하고 기본 브라우저로 엽니다.
- **Quoridor AI Stop**: 앱이 띄운 게임 서버와 AI 프로세스를 종료합니다.

직접 터미널을 열거나 5173 주소를 입력할 필요가 없습니다. 실행기는 매번 최신 게임 화면을 빌드하고, 로컬 빈 포트를 자동 선택합니다. 이미 준비된 앱이 있으면 기존 화면을 다시 엽니다. 기존 개발 서버나 다른 서버를 강제로 종료하지 않습니다. 앱이 직접 소유한 AI 서비스도 별도 빈 포트를 사용합니다.

게임 화면에서 기존 AI 대전·양쪽 직접 조작·AI 관전 모드를 그대로 사용할 수 있습니다. 기본 엔진은 기존 Atlas 5.3입니다. 이번 작업은 실행 편의 개선이며 AI 강도를 바꾸지 않습니다.

브라우저 탭만 닫으면 백그라운드 서버는 남아 다음 실행에 재사용됩니다. 완전히 종료하려면 **Quoridor AI Stop**을 실행합니다. 다음 실행 시 자동으로 다시 시작합니다.

## 요구 환경과 재설치

현재 PC의 Node.js·프로젝트 의존성과 빌드된 Native 엔진을 사용합니다. 엔진이 없거나 소스가 변경됐다면 Rust 빌드를 자동 실행하므로 그때는 Rust 도구가 필요합니다. 프로젝트 폴더를 이동하면 바로가기를 다시 설치해야 합니다. 독립 설치형 앱이나 배포용 단일 실행 파일은 다음 단계입니다.

```powershell
npm run play:shortcuts
npm run play
npm run play:stop
```

실행 상태와 로그는 Git에서 제외한 `.local-app` 폴더에 저장합니다. 준비에 실패하면 바로가기 실행 중 오류 메시지를 표시하고 해당 폴더에 로그를 남깁니다. 긴 최초 빌드는 로그를 확인할 수 있습니다. Node나 프로젝트 의존성이 없는 다른 PC에서는 먼저 개발 환경 설치가 필요합니다.

## 확인 항목

실제 실행기와 Native 엔진을 띄워 빌드 화면 제공, AI 상태 확인·실제 탐색 응답, 중복 실행 시 재사용, 인증 없는 종료 요청 거부, 종료 후 서버·상태 파일 정리를 자동 검사합니다. 실행·종료 바로가기는 Windows 사용자 바탕화면에 생성했습니다.

전체 Node 테스트 72개와 웹 빌드를 통과했습니다. 마지막 실행기 수정 후에는 실행·중복 처리·AI 탐색·종료 통합 검사를 다시 통과했습니다.

## 남은 추천 우선순위

1. 개발 환경이 필요 없는 설치형 데스크톱 앱 제작. 창 닫기와 엔진 종료를 연결하고 설치·업데이트 제공.
2. 실제 사용 엔진·버전·설정을 표시하고 안정 엔진과 실험 후보 선택 기능 제공.
3. 같은 국면·진영 교환·시간 조건의 비교 대전 체계 정비.
4. 속도 최적화·위협 평가·깊이 보호를 각각 검증한 뒤 통과한 변경만 실제 엔진에 반영.
