# 상황 박스 상시 표시와 보드 위치 고정

분석 안내 박스가 나타나거나 사라지고 문구가 여러 줄로 늘어나면서 보드가 밀리는 문제를 수정했다.

- 분석 전·고정 시간·관전·화면 재확인 상태에도 박스를 유지한다.
- 일반 화면은 208px, 720px 이하 화면은 264px로 높이를 고정한다. 제목·설명·시간·추천 변경·판세를 각각 고정된 그리드 행에 배치한다.
- 추천 변경 행의 내용이 없어도 공간을 유지한다. 긴 문구는 지정된 줄 수까지만 표시하며 전체 문구는 title과 우측 분석 내용을 통해 확인할 수 있다.
- 보드 위 상태줄도 한 줄로 제한하여 긴 상태 문구가 보드를 밀지 않도록 한다. 상태 전환으로 높이나 위치를 애니메이션하지 않는다.
- 엔진·탐색·화면 인식 알고리즘은 변경하지 않았다.

웹 빌드 후 사용자의 브라우저와 분리된 헤드리스 Chrome에서 실제 앱의 81칸 렌더를 확인하고, 안내 문구와 알림 유무를 모사해 좌표를 측정했다. 고정 시간·관전·수동 모드 전환도 포함한다. 실제 대국이나 화면 공유 인식 테스트는 아니다.

1280·760·390px의 각 화면 폭에서 13개 상태, 총 39개를 측정했다. 각 폭 안에서 박스 높이 변화와 보드 상단 좌표 변화는 모두 0px이고, 박스는 항상 표시됐다. 화면 크기를 바꾸는 경우에는 해당 반응형 높이가 적용된다. 결과는 geometry.json에 보존했다.
