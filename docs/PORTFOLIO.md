# 포트폴리오 시연 가이드

## 디자인 개선

보드의 청록·분홍은 진영을, 금색은 추천 위치를 나타냅니다. 패널의 명암과 글자 크기로 기능의 위계를 구분하고, 카드와 기보의 선택 상태는 색·테두리·표시를 함께 사용합니다. 보드와 분석 영역은 상태 문구가 달라져도 위치와 높이가 유지됩니다.

대국 종료 시 추천 대기를 승패 결과와 복기 안내로 대체했습니다. 종료 배너의 중복을 제거하고, 모션 감소 설정과 키보드 포커스도 지원합니다. UI 검증은 가상 캡처와 테스트 엔진으로 진행하며 실제 엔진의 실력을 검증하는 자료와 구분합니다.

## 시연 순서

1. 앱을 실행하고 2×2 모드 카드의 선택 상태를 보여줍니다.
2. AI와 대전에서 상대 엔진과 추천 분석 엔진을 독립적으로 선택합니다.
3. 개인 기보를 불러와 수 선택에 따른 자동 분석과 쉬운 설명을 보여줍니다.
4. 화면 연동에서 말과 벽 변화가 동기화되는 모습을 보여줍니다.

## 소개 문장

“쿼리도 게임 화면을 인식해 보드와 기보를 자동 동기화하고, 로컬 AI의 추천 효과를 쉬운 문장으로 설명하는 분석 도구입니다. 외부 모델·게임 기반 위에 인식, 합법 진행 검증, 시간 제한 추론, 취소·캐시와 분석 UX를 통합했습니다.”

## 확인할 증거

- 실제 브라우저 모델·서버 없는 AI 대전: `npm run browser:qa`
- 브라우저/Python 차이와 구조: [실행 구조](ARCHITECTURE.md)

- 화면·세션·기보 흐름: `npm run screen:qa`
- 취소·시간 예산: `scripts/qa/check-sigma-latency.mjs`
- 벽 판정 동등성: `scripts/qa/check_sigma_fast_walls.py`
- 로컬 측정 파일: `reports/latency-fix-20261106/` (생성 보고서이므로 Git에는 기본 포함하지 않음)
- 공개 스크린샷: `docs/images/portfolio-desktop.png`

생성 보고서가 없는 복사본에서는 검증 명령을 다시 실행합니다. 응답 시간 비교는 동일 PC·동일 배치·동일 요청 설정에서 하고, 초기 모델 로딩과 실제 계산을 구분합니다. 속도 개선과 승률 개선은 별개로 설명합니다.
