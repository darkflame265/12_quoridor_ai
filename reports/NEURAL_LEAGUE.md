# 신경망과 Atlas 5.3 직접 대전 리그

학습된 CNN을 승인된 Atlas 5.3 Native Rust 및 과거 신경망과 같은 수당 시간 예산으로 비교하는 평가 경로를 추가했습니다. 학습 코드나 기존 모델의 학습 해시는 변경하지 않습니다. 게임 화면에서 학습하거나 실전 엔진을 교체하는 기능은 아닙니다.

## 실행

네이티브 엔진을 빌드하고 README의 GPU Python 환경을 설치한 상태에서 실행합니다. 승인된 Atlas 5.3을 확인할 수 없으면 다른 엔진으로 몰래 바꾸지 않고 평가를 중단합니다. 이미 실행 중인 웹 서버나 AI 서비스와 별도의 평가용 프로세스를 사용합니다.

```powershell
npm run native:build
npm run neural:league -- --out reports/neural-league/my-evaluation
```

기본 후보는 `models/experimental-rescnn/experimental.pt`, 과거 상대는 `models/bootstrap-checkpoint.pt`입니다. 상대 모델을 여러 개 지정할 수 있습니다.

```powershell
npm run neural:league -- --out reports/neural-league/my-models --candidate models/experimental-rescnn/experimental.pt --opponent models/bootstrap-checkpoint.pt --opponent training/runs/other/snapshots/iteration-000001.pt
```

두 번째 상대 경로는 예시이며 실제 존재하는 체크포인트를 지정해야 합니다. 후보와 상대 파일의 해시가 같으면 거부합니다. 출력은 비어 있는 새 폴더를 사용합니다.

## 평가 조건과 채택 기준

- 기본값은 수당 500ms, Native 4코어입니다. CNN과 과거 신경망은 GPU 정책·가치 추론과 단일 MCTS 탐색을 사용합니다. 규칙 계산·전송·추론을 신경망 시간에 포함합니다.
- Native는 직접 프로세스 통신을 사용합니다. 웹 UI 통신 지연을 비교하는 시험은 아닙니다. 양쪽 요청 시간은 같지만 계산 방식이나 CPU 코어 사용량이 동일한 것은 아닙니다.
- 게임마다 Native 프로세스와 신경망 규칙 캐시를 초기화합니다. 신경망별 규칙 캐시를 분리하며 추론 초기화는 대전 전에 합니다.
- 일반 배치와 벽 미로를 각각 진영 교환합니다. 기본 `--pairs 5`는 각 상대당 검증 20판입니다. 기본 상대 2종이면 검증 40판이며, 통과할 때만 별도 holdout 40판을 실행합니다.
- 합법 수·상태 전이는 독립 JavaScript 규칙으로 매 수 확인합니다. 대국 기보와 수별 시간·MCTS 계산량을 저장합니다. 반복 3회와 수 제한 종료는 평가용 무승부입니다.
- 16개 전술 문제 통과, 상대별 검증·holdout 최소 20판, 승리 비율의 Wilson 하한 0.5 초과, 두 배치 유형 모두 양의 승패 차, 시간 초과 비율 5% 미만을 요구합니다. 무승부를 승률 계산에서 빼서 과대평가하지 않습니다.
- 시간 초과는 `요청 시간 × 1.2 + 5ms`를 넘긴 수입니다. 한 번의 규칙 계산·추론은 중간에 끊을 수 없어 엄격한 실시간 상한은 보장하지 않습니다. 실제 초과 횟수와 최대 시간을 보고합니다. 전술 문제도 같은 허용 시간을 검사합니다.
- 진영 교환 대국은 서로 상관될 수 있습니다. Wilson 수치는 보수적 운영 기준이며 인간 상대 실력이나 통계적 독립성을 인증하지 않습니다.

검증에서 탈락하면 holdout 배치를 열지 않습니다. holdout은 이번 후보 평가에서 따로 보관하는 기존 v3 배치이며, 프로젝트 전체에서 한 번도 사용하지 않은 새 외부 시험이라고 주장하지 않습니다. 다음 반복 개발에서 독립 시드를 계속 확보해야 합니다.

## 결과 보관과 재검증

이번 실제 확인은 `--pairs 1 --ms 500 --cores 4 --max-plies 120`으로 실행했습니다. 일반·미로 각 한 배치의 진영 교환을 두 상대에 적용한 총 8판입니다. 승격용 최소 표본을 채운 시험이 아닙니다.

| 상대 | CNN 결과 |
| --- | --- |
| Atlas 5.3 Native Rust | 0승 3패 1무 |
| 과거 MLP 128 | 3승 1무 |

전술 문제 16/16을 통과했고 모든 대국에서 양쪽 모두 허용 시간을 넘긴 수는 0개였습니다. 무승부 2판은 반복 종료였고 수 제한 종료는 없었습니다. 후보는 채택되지 않았으며 holdout은 실행하지 않았습니다. 기존의 고정 32회 탐색 평가와 조건이 달라 결과를 직접 합산하면 안 됩니다. 아직 신경망이 기본 Native 엔진을 대체할 수준이라는 근거는 없습니다.

전체 8판의 기보·수별 시간과 채택 여부는 [실제 보고서](neural-league/initial-500ms/report.json), [채택 기록](neural-league/initial-500ms/selection.json)에 있습니다. 실제 대국 외에도 마감 시간 종료·종국 수 반복 탐색, 진영 편향·무승부·중복 대국·전술 실패·시간 초과에 대한 승격 거부를 자동 테스트했습니다. 앱 테스트 63개, Python/GPU 테스트 22개 및 빌드를 통과했습니다.

`report.json`에 후보·과거 상대·Native 바이너리·승인 자료·평가 코드·규칙 해시를 저장합니다. `games/`에는 전체 기보와 수별 기록을, `selection.json`에는 보고서와 후보 해시에 연결된 실험 채택 여부를 저장합니다. 중단된 평가에는 채택 기록을 만들지 않습니다.

```powershell
.venv-gpu\Scripts\python.exe training/verify_league.py reports/neural-league/initial-500ms
```

재검증은 보고서·모델·소스·Native 해시, 기보의 합법성과 승패, 시작 배치·수별 기록·시간 집계, 채택 결정을 다시 확인합니다. 채택은 이 평가의 연구 후보 선정만 뜻하며 `models/registry.json`이나 실전 Native 승인 자료를 바꾸지 않습니다. 신경망 실전 통합은 이후 별도 작업입니다.

## 남은 추천 우선순위

1. Atlas 5.3의 지도 자료와 다양한 미로 자가대국으로 정책·가치 예측 개선.
2. 개선된 후보에 기본 규모 리그를 실행하고 추가 미사용 시드에서 검증.
3. 통과한 신경망의 GPU 추론·탐색을 실전 서비스와 연결하고 0.5초 지연 검증.
4. 독립 외부 엔진·숙련자 대전으로 실제 실력 검증.
