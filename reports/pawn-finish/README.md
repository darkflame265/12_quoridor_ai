# 0.4의 불필요한 마지막 벽 사용 보정

## 적용

- 상대 벽이 0개이고 내 벽이 남아 있으면, 현재 벽 배치에서 이동만 하는 종반 해법을 먼저 조회한다.
- 이동만으로 승리하는 경우에만 합법적인 이동 전략을 선택한다. 내 벽은 소비하지 않는다. 상대의 모든 선택은 이동이므로 이 승리 전략은 원래 게임에서도 유효하다.
- 이동 전용 해법이 무승부·패배이거나 제한 시간 내 계산하지 못하면 일반 검색을 계속한다. 내 벽을 버리거나 원래 게임의 패배로 단정하지 않는다.
- 마지막 벽 사용의 승리 결과가 이미 확인된 더 빠르거나 같은 길이의 이동 승리 전략을 덮어쓰지 않도록 했다.
- 화면과 JSON의 `winProof`에 승리 확인 근거, 보장된 최대 행동 수, 벽 사용 여부, 전체 행동 중 최단 승리를 증명했는지를 구분한다. 이동 전용 전략의 승리 확인을 전체 행동의 최단 승리 증명으로 표시하지 않는다.
- 전진 우선 처리는 골인 안전 0.4에 적용한다. 기본 5.3 및 0.2·0.3의 선택 정책은 유지한다. 기존 마지막 벽 승리 결과에는 설명용 근거 정보를 추가한다.
- 실행 중인 파일을 교체하지 않도록 빌드를 별도 폴더에 준비하고, 실행기를 통해 같은 주소의 서버를 갱신한다.

## 수행 범위

사용자 요청에 따라 회귀 사례 추가, 단위·브라우저 테스트, 기보 재탐색, 대전 검증은 생략했다. 실행파일과 웹 번들 빌드 및 실제 서비스의 버전·빌드 연결 확인만 수행한다. 기존 대전·테스트 결과를 이번 수정의 검증 결과로 재사용하지 않는다.

서비스 갱신 정보는 `live.json`에 보관한다. 앱을 새로고침하고 골인 안전 0.4를 선택한 뒤 화면 공유를 다시 연결한다.
