# 효과가 작은 벽의 반복 소비와 말 이동 비교

Atlas 0.4 보완 빌드. 5.3 원본은 유지한다. 이전 빌드의 방어벽 보존 평가에 이어 루트의 약한 벽 소비 비용을 추가한다.

## 범위

- 자기 차례의 연속 벽 설치 횟수를 관측된 records에서 계산한다. 상대의 수는 건너뛰고 내 말 이동이 나오면 종료한다. baseState.turn을 반영하며 최대 10회다. 가져온 배치·재동기화 이전의 알 수 없는 횟수는 추정하지 않는다.
- 고정·가변·관전 분석에서 Native 요청의 부가 상태 wallStreak로 전달한다. 게임 규칙 상태와 boardKey에는 포함하지 않는다. 값이 없으면 매 요청 0으로 초기화하며 Rust 진입점에서도 최대 10으로 제한한다.
- 합법 말 이동 중 최단 거리를 줄이는 이동이 있을 때만 비교한다. 상대 최단 거리 증가가 0~1칸인 벽에 소비 비용을 부과한다. 루트 수를 금지하지 않으며 내부 평가와 승패 증명은 변경하지 않는다.
- 비용: `24 + 16×min(연속 설치,4) + (상대 지연 0 이하이면 24) + 12×min(내 경로 증가,2)`로 최대 136점이다. 전진 대안이 있는 상황에서 벽을 아낄 수 있도록 기존 탐색 점수에 더하는 휴리스틱이며 최적성 증명은 아니다.
- 바로 승리할 이동이 있거나 상대가 바로 골인할 수 있으면 비용을 적용하지 않는다. 상대의 합법 이동 선택지를 줄이는 벽, 측정된 최강 단일 벽 위협을 줄이는 벽, 기존 보존 평가에서 위협을 모두 제거한 벽도 면제한다. 모든 준비 벽의 가치를 검증하는 기능은 아니다.
- 추가 계산은 남은 시간의 8%와 30ms 중 작은 값 이내다. 중간 취소·시간 초과면 부분 비용은 모두 폐기한다. 후보 계산 중 원본 상태를 복원하거나 복제한다.
- 화면과 JSON의 weakWallConsumption으로 관측된 연속 설치 횟수·전진 대안·비용 적용 후보 수·선택된 벽의 비용을 확인할 수 있다.

## 제한적 확인

Rust 릴리스·웹 빌드를 완료했다. 최근 기보의 세 위치를 이전 방어벽 보존 빌드와 새 빌드 각각 500ms·4코어의 새 프로세스로 확인했다.

|위치|기존|변경 후|
|---|---|---|
|19수 직전 / 연속 벽 7회|h8 가로|f7 말 이동|
|21수 직전 / 연속 벽 8회|d8 가로|동일, 상대 거리를 2칸 늘려 약한 벽 대상에서 제외|
|23수 직전 / 연속 벽 9회|d7 세로|동일, 측정된 현재 단일 벽 위협을 차단해 면제|

모든 결과가 해당 배치에서 합법이었다. 단일 위치에서 수가 바뀐 것은 대국 승리나 실력 향상의 증거가 아니다. 이전 사용자 요청에 따라 긴 대전 및 전체 테스트는 실행하지 않았다. 입력 배치와 결과는 diagnostics.json에 보존한다.

다음 우선순위는 중반 연결 벽 공격과 미래 경로 취약성 평가, 이후 위험 상황의 가변 계산 활용이다.
