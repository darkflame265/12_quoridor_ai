# 엔진 목록 및 기본 설정 정리

- 플레이·관전 엔진 선택은 Atlas 0.4 최신과 Atlas 5.3 안정 두 가지로 제한한다. 0.4의 우월성이 검증됐다는 의미는 아니다.
- 플레이 기본값: 화면 연동, Atlas 0.4, 가변 0.5초 목표~최대 15초. 관전 기본 비교는 청록 0.4 대 분홍 5.3이며 각 진영의 고정 시간으로 착수한다.
- 구 설정은 최초 복원 시 한 번 새 기본값으로 옮긴다. settingsRevision 1을 저장하여 이후 사용자의 선택을 유지한다. 배치·기보·추천 기록은 변경하지 않는다.
- 명시적으로 불러온 기보의 지원 엔진·시간·모드는 유지한다. 지원 종료된 엔진은 새 분석을 위해 0.4로 매핑하고 안내한다. 과거 decisionLog는 그대로 유지한다.
- 실행기와 개발 서비스에서 0.2·0.3·late-full 서비스를 준비하지 않고 프록시도 제거한다. 기존 평가 자료·공유 Rust 소스·5.3의 WASM 대체 실행 의존 코드는 보존한다.
- 브라우저 화면 공유는 사용자가 허용해야 한다. 화면을 가져와 검토·적용하면 자동 감시가 시작되는 기존 흐름을 유지한다.

엔진의 벽 평가 로직은 이번 변경에 포함하지 않는다. 다음 개선 순서는 마지막 1~3개 벽의 방어 가치, 0~1칸 지연 벽의 반복 비용, 중반 연결 벽 공격에 의한 경로 취약성, 위험 상황의 가변 계산 활용이다.

웹 빌드·실행기 및 개발 서비스 구문·실행 앱의 서비스 상태와 배포 설정을 확인한다. 기존 요청에 따라 테스트 대전은 생략한다.
