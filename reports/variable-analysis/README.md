# 가변 생각 시간

생각 시간에서 `가변 · 0.5초부터 최대 15초`를 선택합니다. 화면 연동의 자동 분석과 수동 최선 수 분석에 적용됩니다.

- 한 번의 15초 탐색에서 완료된 깊이의 결과를 받습니다. 0.5초에 확보된 추천을 처음 표시하고, 이후 완료된 깊이가 나오면 갱신합니다. 엔진이 먼저 탐색을 마치면 바로 최종 결과를 표시합니다.
- 0.5초는 첫 표시 목표입니다. 엔진 준비·완전 탐색 등으로 완료된 결과가 없으면 더 기다립니다. 오래 계산한다고 반드시 더 좋은 수를 보장하지는 않습니다.
- 현재 추천 고정은 보드의 추천을 유지하며 계산은 계속합니다. 최신 수와 깊이는 별도 상태에 표시됩니다. 고정을 해제하면 최신 추천을 표시합니다.
- 배치·차례·엔진·모드·시간·코어가 바뀌거나 감시가 불확실해지면 취소합니다. 이전 결과는 새 배치에 표시하지 않습니다. 첫 추천 이후에는 직접 착수할 수 있습니다.
- 가변 계산은 선택 코어 수와 논리 코어 수에서 하나를 제외한 값 중 작은 값을 사용합니다. 최소 1코어입니다.
- AI 자동 착수는 가변 설정에서도 0.5초를 사용합니다. AI끼리 관전은 각 진영의 고정 시간 설정을 유지합니다.
- JSON의 decisionLog에 분석 시작·최신 결과·표시 결과·고정 여부를 구분하여 저장합니다. 실제 행동에는 표시 추천과 최신 계산 각각의 일치 여부를 기록합니다.

기존 Atlas 엔진 평가 함수와 승격 상태는 변경하지 않았습니다. 엔진 자체의 조기 종료 조건도 유지합니다. 이 변경은 추가 계산 시간을 활용하는 분석 방식이며 실력 향상이 검증된 새 엔진은 아닙니다.

검증: 웹 배포 빌드. 사용자의 이전 요청에 따라 테스트 및 대전 검증은 실행하지 않았습니다.
