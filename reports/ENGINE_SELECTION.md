# 사용 엔진 표시와 안정·실험 엔진 선택

AI 대전·직접 조작의 분석 엔진은 플레이 설정의 **사용 엔진**에서 선택합니다. AI 관전에서는 청록·분홍의 엔진을 각각 선택할 수 있습니다.

| 선택 | 실행 내용 |
| --- | --- |
| Atlas 5.3 안정 | 검증을 통과해 기본으로 유지한 Native 엔진. 연결 실패 시 Atlas 4 WASM으로 대체하며 상태에 표시합니다. |
| Atlas 실험 late-full | 미승격인 중후반 위협 평가 후보. Native 프로토콜 버전은 5.9 experiment이며 빌드 식별자와 late-full 설정을 표시합니다. |
| Atlas 4 WASM | 브라우저 안에서 WASM 실행 |
| Atlas 3 | 기존 단일 코어 엔진 |

실험 후보는 강하다고 검증된 엔진이 아닙니다. 최근 개발 대전은 1승 3패였습니다. 후보를 직접 대전·관전하고 비교할 수 있게 노출한 것이며, 안정 엔진을 교체한 작업은 아닙니다.

## 동작

- 엔진 상태 줄에 실제 Native 연결의 버전·후보 설정·빌드 식별자 또는 WASM 대체 사용을 표시합니다. 관전 엔진은 처음 계산할 때 연결을 확인합니다.
- 실험 엔진을 사용할 수 없으면 오류를 표시하고 멈춥니다. 안정 엔진이나 WASM으로 조용히 대체하지 않습니다.
- 실험 엔진은 별도 프로세스와 고정된 late-full·legacy 정렬·legacy 연결도·180/30 계수를 사용합니다. 안정 엔진과 환경·캐시를 공유하지 않습니다.
- 엔진 변경 시 진행 중인 계산과 상대 차례 계산을 취소합니다. 관전은 일시정지하고 이전 결과가 다음 수로 적용되지 않도록 기존 세대 구분을 유지합니다.
- 기보 파일에 대전용 엔진과 관전 양쪽 엔진 설정을 함께 저장합니다. 이전 기보에 대전용 엔진 설정이 없으면 안정 엔진을 선택합니다.

## 실행

이미 실행 중이었다면 **Quoridor AI Stop → Quoridor AI** 순서로 다시 실행하세요. 실행기가 실험 엔진의 빌드 상태를 검사하고 필요한 경우 빌드합니다. 최초 실험 빌드에는 Rust 도구가 필요합니다. 빌드 실패 시 안정 엔진은 계속 사용할 수 있고 실험 선택은 사용 불가로 표시합니다.

개발 서버는 `npm run dev`로 시작할 때 두 서비스를 준비합니다. 기존 서비스가 남아 있으면 재시작하거나 바탕화면 실행기를 사용하세요. 안정 서비스만 단독 실행하는 기존 `native:serve`는 실험 서비스를 시작하지 않습니다.

## 검증

실제 실행기에서 안정·실험 상태 메타데이터와 서로 다른 버전을 확인하고 각각 AI 수 계산을 실행했습니다. 실험 엔진 오류 시 다른 엔진이 계산하지 않는 검사, 취소·재사용·종료 검사도 포함합니다. Native Rust 알고리즘과 기존 안정 엔진 승격 기록은 변경하지 않았습니다. 과거 진단·대전 기록의 소스 해시 검증은 해당 커밋에서 수행합니다.

## 남은 추천 우선순위

전체 Node 테스트 74개와 웹 빌드를 통과했습니다. 최종 변경 후 엔진 선택·실제 안정/실험 응답 버전·실행기 종료 통합 검사도 다시 통과했습니다.

1. 같은 시작 국면·진영 교환·시간·코어로 안정·실험 엔진을 자동 비교하고 결과 저장.
2. 개발 도구 없이 실행하는 설치형 데스크톱 앱과 종료·업데이트 흐름.
3. 속도·위협 평가·깊이 보호를 따로 검증하고 통과한 변경만 기본 엔진 반영.
4. 검증된 엔진을 활용한 지도 자료 생성과 GPU 학습 재검토.
