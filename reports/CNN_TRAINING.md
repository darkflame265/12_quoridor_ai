# 잔차 CNN 정책·가치망 학습

보드 구조를 처리하는 CNN과 MCTS 자가대국 학습을 구현하고 RTX 3060 Ti에서 실제 학습했습니다. 실전 기본 엔진은 Atlas 5.3을 유지합니다. 이번 신경망은 실험 모델이며 승격되지 않았습니다.

## 구현

- 9×9 보드를 말·벽·목표선·남은 벽 등 9개 평면으로 표현합니다. 64채널, 잔차 블록 4개, 파라미터 343,572개입니다.
- 정책 출력은 이동 81개와 가로·세로 벽 각 64개이며, 가치 출력은 현재 차례 관점의 승패입니다. GroupNorm으로 추론 배치 구성에 따른 통계 변화를 피합니다.
- 기존 MLP 체크포인트를 지원하며 CNN 형식을 별도로 식별합니다. 브라우저의 기존 MLP 로더로 CNN을 잘못 읽지 않도록 구분합니다.
- 전체 체크포인트는 가중치·옵티마이저·리플레이·검증 자료·난수 상태·이전 상대 모델을 저장합니다. 코드 해시가 변경된 전체 재개는 거부하며, 가중치만 가져오는 새 학습은 별도로 지원합니다.
- 검증 자료는 대국 단위로 분리하고 동일 상태가 학습 자료에 섞이지 않도록 제외합니다. 반복별 검증 손실이 가장 낮은 모델을 별도 저장합니다. 이 선택은 대전 실력 승격과 별개입니다.

## 실제 결과

기존 32판 1,208개 표본에서 검증 7판 253개를 고정하고, 겹치는 상태 46개를 제외해 909개로 초기 학습했습니다. 이후 MCTS 32회 탐색으로 128판을 생성했습니다. 목표선 도착 120판, 반복 무승부 8판이며 수 제한 종료는 없었습니다. 추가 표본 5,245개 중 검증 상태와 겹친 169개를 제외했고 최종 학습 자료는 5,985개입니다.

초기 학습 1회와 추가 학습 4회 후 검증 합산 손실은 6.6589에서 3.5388로 감소했습니다. 최종 정책 손실은 2.4010, 가치 MSE는 1.1378, 정책 최상위 일치율은 62.45%입니다. 가치 0을 항상 출력하는 기준 MSE는 1.0이므로 가치 예측은 아직 개선이 필요합니다. 손실 감소를 실전 실력 향상으로 해석하지 않습니다.

| 상대 | 최종 결과 |
| --- | --- |
| Atlas 4 Rust/WASM | 0승 4패 |
| 이전 MLP 128 | 3승 1무 |
| 초기 CNN 모델 | 1승 3무 |

신경망은 수당 MCTS 32회, Rust/WASM은 20ms 조건입니다. 동일 시간 비교가 아니며 실제 계산 시간도 보고서에 기록했습니다. 전술 문제는 16/16을 통과했지만 표본 수와 대전 성적 모두 실전 승격에 충분하지 않습니다. Native Atlas 5.3과의 직접 리그는 다음 과제입니다.

CPU/GPU 추론의 최대 오차는 약 0.00000334였고, 학습·검증 상태 중복은 0개입니다. 저장한 128개 기보는 독립 JavaScript 규칙으로 재검증했습니다. 별도 GPU 생성 확인도 CNN으로 8판·319개 표본을 만들었습니다.

## 실행과 재개

기존 GPU 환경 설치 방법은 README의 GPU 학습 설명을 따릅니다. 아래 명령은 `.venv-gpu`의 CUDA PyTorch를 사용합니다. 출력은 새 폴더를 지정하세요.

```powershell
npm run train:cnn -- --out training/runs/my-cnn
npm run train:cnn -- --out training/runs/my-cnn --resume
```

기본 실행은 기존 자료로 초기 학습한 뒤 32판씩 4회 자가대국과 학습을 실행합니다. `--rounds`, `--games`, `--simulations`로 규모를 조절합니다. 실전 엔진을 자동 교체하지 않습니다.

전체 재개용 체크포인트는 로컬 `training/runs/rescnn-main-v1/checkpoint.pt`에 있으며 Git에는 포함하지 않습니다. 저장소의 `models/experimental-rescnn/experimental.pt`는 선택된 가중치만 담은 이동 가능한 모델입니다. 이 파일은 `--resume` 대신 `--init-checkpoint`로 새 학습에 사용합니다.

```powershell
.venv-gpu\Scripts\python.exe training/train.py --init-checkpoint models/experimental-rescnn/experimental.pt --replay-dir reports/gpu-batch/dataset-smoke --validation-fraction 0.2 --games 0 --iterations 1 --out training/runs/cnn-from-export
```

재개 검증에는 CPU에서 중단 없는 2회 학습과 1회 후 저장·재개한 학습의 가중치·난수·레지스트리 일치를 포함합니다. 보고서와 모델은 소스·규칙·파일 해시로 연결됩니다. 학습 코드를 수정한 뒤에는 기존 전체 체크포인트의 동일 실행 재개 대신 새 학습을 시작해야 합니다.

## 남은 추천 우선순위

1. Native Atlas 5.3과 과거 모델을 상대하는 리그, 동일 시간 대전과 승격 기준 연결.
2. 강한 엔진의 지도 자료와 다양한 미로 자가대국 확대, 가치 예측 개선.
3. 충분한 미사용 배치·진영 교환 대전으로 실제 강도와 0.5초 계산 예산 검증.
4. 검증을 통과한 신경망의 실전 GPU 추론과 탐색 통합.
5. 독립 외부 엔진·숙련자와 대전해 외부 실력 검증.
