# Sigma 2·3·4 프로젝트 정리

현재 실행·관전 엔진은 Sigma2·Sigma3·Sigma4만 지원한다. Sigma4가 공유하는 Sigma3 추론·전술 코드, Sigma2 기준 추론 코드와 공통 ONNX 모델·게임 규칙·MCTS·라이선스는 보존했다.

## 삭제와 보존

- 삭제 파일 크기 합계 **14,036,985,941바이트(약14.04GB)**. 디스크 압축·하드링크에 따른 실제 확보 공간과는 다를 수 있다.
- GPU 가상환경 약4.60GB, 외부 다운로드·비교 실행 파일 약4.01GB, 이전 Rust 엔진 계열 약5.25GB, 과거 Atlas 학습·분석 산출물 등을 제거했다.
- 현재 사용하는 전역 Python의 NumPy·ONNX Runtime은 변경하거나 삭제하지 않았다. 실행 의존성은 requirements.txt에 기록했다.
- 기존 미커밋 변경과 실험 자료65개 경로를 보호했다. 모델·추론·규칙·MCTS·전술 파일11개의 SHA256이 정리 전후 동일하다. 일부 진행 중인 UI/서비스 수정은 정리 커밋에 섞지 않고 작업 트리에 남긴다.
- Sigma 연구·회귀 자료는 유지했다. 정리 후 reports 약133MB, evaluation 약41MB는 이 자료와 공용 기보 검증 자료다. Git 이력과 node_modules도 유지한다.
- .local-app에는 삭제 작업 목록과 작은 작업 보존본이 있다. 대용량 폴더 전체를 복사한 백업은 만들지 않았다. 삭제한 Git 추적 파일은 Git 이력으로 복구할 수 있다.

## 실행 경로 정리

실행기가 Sigma 세 서비스만 시작하도록 변경했다. Atlas 빌드·핫 리로드·이전 엔진 API와 웹 검색 Worker/WASM 연결을 제거했다. 공통 HTTP 전달 코드는 Sigma 서비스가 사용하므로 유지했다. 개발 서버도 Sigma 세 API를 사용한다.

엔진 선택과 세션 복원은 Sigma2·3·4만 허용한다. 이전 엔진 기보의 수와 배치는 보존하되 새로운 분석에는 Sigma4를 연결한다. 정상 엔진이 연결되지 않으면 다른 엔진으로 몰래 대체하지 않는다.

## 검증

- 게임 규칙·화면 판독·동기화·기보·세션·선택·실행 잠금 검사106개 통과.
- 실제 세 Sigma 서비스에서 각각 ONNX/PUCT 추론과 합법 수 반환 확인. 이는 전체 실력 비교가 아니다.
- 격리 브라우저의 합성 화면/합성 서비스로 엔진 목록·Wallz 자동 적용·재동기화·관전·기보 가져오기 확인. 실제 엔진 검사는 별도로 수행했다.
- Rust 디렉터리가 없는 상태에서 웹 빌드와 고정12324 서버 시작 성공. Sigma 세 health는200, 제거한 native/goal/sigma API는404.
- 브라우저 기보 보관 데이터나 다운로드 폴더의 사용자 기보는 삭제하지 않았다.
