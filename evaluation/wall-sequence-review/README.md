# 연속 벽 소비 평가 적용

기존 우선순위인 연속 벽 소비를 묶어서 평가하는 기능을 적용했다. 남은 기존 항목은 안내 오류 정리 하나다. 새 우선순위는 추가하지 않았다.

## 적용 방식

기보에서 확인된 최근 연속 자기 벽 최대10개와 각 차례의 최선 즉시 전진량을 전달한다. 수입 배치 이전에 쓴 벽이나 누락된 이력은 추정하지 않는다. 네이티브에서는 현재 보드에 존재하고 현재 진영 소유인 벽만 중복 없이 받아들인다. 사전 계산 재사용 조건에도 동일한 연속 벽 이력이 필요하다.

각 후보 벽은 현재 말 위치를 고정하고, 관측한 자기 연속 벽 묶음만 제거한 기준 미로와 비교한다. 상대의 각 합법 말 이동·점프 뒤 가장 적게 남는 지연을 사용한다. 내 우회와 각 과거 차례의 전진 대안 합을 함께 비교하며 묶음 비용은 최대96점이다. 후자는 일관된 대체 경로의 실제 도착 손실 증명이 아닌 기회비용 추정이다.

상대보다 재고가 적어지고 남은 벽이2개 이하가 되는 소비에는12~36점의 별도 비용을 반영한다. 기존 측정된 재고 비용이 있는 후보에는 같은 비용을 중복 부과하지 않는다. 즉시 골인을 막는 상황과 측정된 공격을 약화시키는 후보는 비용에서 제외한다. 기존 약한벽 비용을 합친 전체 비용은160점으로 제한한다. 합법 수나 승패 점수를 바꾸지는 않는다. 비교 시간 초과는 미완료로 표시하고 부분 비용을 적용하지 않는다.

## 짧은 비교 결과

변경 전 기준은 e463687b829d 바이너리다. 각 위치·버전마다 새 프로세스, 작업1개·완료 깊이4로 비교했다.

- 17수: d9 세로벽 유지. 기존 비용88점에 묶음 비용64점이 추가됐다. 이전 연속4개와 후보를 합친 전진 대안 합은5칸, 상대 이동 후 남는 지연은1칸이었다.
- 23수: f3 세로벽 유지. 측정된 방어 효과가 있어 비용 면제를 유지했다.
- 37수: b4 가로벽에서 d4 이동으로 변경돼 마지막 벽을 남겼다. b4 가로벽에는 별도 재고 비용36점이 적용된다.
