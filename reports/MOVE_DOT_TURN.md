# 합법 이동 점으로 차례 판독

2026-10-29. 사용자가 제시한 초기 배치에는 내 말 옆·앞의 점 3개가 보이는데, 문구·카드 판독 실패로 적용이 막혔습니다. 기존에는 작은 점을 말에서 제외할 뿐 차례 근거로 활용하지 않았습니다. 이제 점의 색과 위치를 실제 합법 이동과 대조합니다. AI 엔진·모델·기본 승격 상태는 변경하지 않았습니다.

## 사용법

1. 앱을 새로고침하고 게임 화면을 다시 연결하거나 **현재 프레임 고정**을 사용합니다.
2. **원본 차례 표시 자동 판독**을 켠 상태에서 말·벽과 이동 점이 명확하면 **내 차례 · 청록/분홍 이동 점 N개 · 합법 이동 전체 일치**라고 표시합니다. 원본 문구·카드가 판독되지 않아도 적용 버튼이 활성화됩니다.
3. 확인한 배치를 적용하고 자동 감시를 시작합니다. 점·문구·카드·합법 진행을 대조해 내 차례에만 추천합니다.
4. 점이 사라지거나 일부만 보이면 점 근거는 미확정입니다. 문구·카드가 명확하면 해당 근거를 사용하고, 모든 근거가 없으면 이전 추천을 지우고 재확인합니다. 점이 없다는 사실만으로 상대 차례를 만들지 않습니다.

현재 화면의 아래 출발 줄 색이 내 진영이라는 설정은 유지합니다. 이동 점이 분홍이면 분홍 말의 합법 이동과 대조하며, 내 말과 가까워 보인다는 이유로 색이나 소유자를 바꾸지 않습니다.

## 판독과 검증 기준

- 칸 중앙의 작은 색 영역을 읽습니다. 큰 말·링, 벽과 회색 표시를 제외하고 크기·중심 위치·원형에 가까운 채움 비율을 검사합니다.
- 출발 줄 배경 자체를 점으로 읽지 않도록 각 칸 모서리의 배경색과 비교합니다. 말보다 어두운 청록·분홍 점도 지원합니다.
- 인식한 말과 벽이 유효한 배치인지 먼저 확인하고, 독립 규칙 엔진으로 양쪽 말의 합법 이동을 계산합니다. 위·아래 시점 변환과 벽·직선 점프·대각 점프를 반영합니다.
- 같은 색의 관측 점이 **그 말의 합법 이동 칸 전체와 정확히 일치**할 때 차례 근거로 채택합니다. 1·2·3·4·5개가 모두 가능하며 3개를 고정 조건으로 쓰지 않습니다.
- 일부 점 누락, 불법 칸의 추가 점, 잘못된 색, 불확실한 말·벽에서는 점 근거를 채택하지 않습니다. 양쪽의 완전한 이동 점이 동시에 보이면 충돌로 보류합니다.
- 명확한 점 근거와 명확한 원본 문구·카드가 반대 차례를 가리켜도 보류합니다. 배치·차례가 연속 3프레임 안정되면 복구하며, 계속 충돌하면 수동 보정·재동기화를 사용합니다.
- 진단 JSON의 `context.dotEvidence`와 `context.diagnostic.dotChecks`에 관측 점·예상 합법 이동·색별 일치 여부를 기록합니다. 픽셀 이미지나 영상은 저장·업로드하지 않습니다.

## 검증

- 전체 Node 테스트 **138개 통과**, 웹 빌드 통과.
- 초기 점 3개, 두 배율과 어두운 점, 분홍 아래 시작, 이동 칸 1·2·4개, 직선·대각 점프 5칸, 점 누락·추가·잘못된 색·중립 표시·작은 사각형·벽 충돌을 검사했습니다.
- 별도 headless Chrome의 **41개 시나리오 통과**, 처리되지 않은 페이지 오류 0개. 문구와 활성 테두리를 모두 없앤 합성 영상에서 초기 점 3개만으로 적용 버튼 활성화→내 차례 추천까지 확인했습니다.
- 점이 사라지면 상대 차례로 넘기지 않고 추천을 지우며, 카드 근거와 다음 네 점 근거로 합법 수 추적·추천을 재개하는 흐름도 확인했습니다. 반대 문구와의 충돌·분홍 점 판독도 검사했습니다.

## 제한과 남은 추천 우선순위

클라이언트가 이동 점 일부만 표시하거나 점을 숨기는 설정이면 이 근거만으로 차례를 확정하지 않습니다. 인식한 벽이 틀려 합법 이동이 달라진 경우에도 점을 억지로 맞추지 않습니다. 화면에서 실제 벽과 같은 색의 미리보기를 구분하는 기존 한계는 남습니다.

1. **실제 실패 프레임·배율 회귀 검증**: 점 크기·밝기·누락과 벽 인식 오류를 진단으로 구분해 실제 환경에서 정확도와 복구 지연을 측정합니다.
2. **원본 기보 착수·잔여 벽 숫자 판독**: 점·MOVES 번호와 별도의 근거를 확보해 벽 미리보기와 누락 진행을 검증합니다.
3. **6수 초과·되돌리기·새 게임 복구**: 원본 기보를 활용해 자동 재연결 범위를 늘립니다.
4. **진단 표시·지원 화면 확대**: 관측 점과 예상 합법 이동을 시각화하고 부분 점 표시·다른 테마·언어를 지원합니다.
5. **프레임 처리 속도 최적화**: 격자·점·문구 판독 비용과 전체 지연을 계측합니다.
