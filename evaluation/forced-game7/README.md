# 기보 7: 강제 착수 비교와 조기 종료 수정

## 결론

13·17·19수를 악수라고 확정할 근거는 아직 없다. 후보들을 실제로 강제 적용해 상대 차례부터 계산하면, 13수와19수 대안은 실전 수보다 일관되게 좋지 않았다. 17수는 더 깊은 비교에서 e5가 약간 높았으나 큰 폭의 일관된 개선은 입증되지 않았다. 앞선 위험도 차이만으로 추천이 잘못됐다고 설명한 판단을 수정한다.

더 이른 9수에서 검증 가능한 문제가 발견됐다. 실제 e5 이동과 e8 세로벽을 강제로 두고, 동일한 단일 코어·동일한 완료 깊이의 상대 응수를 비교했다.

| 강제 착수 뒤 완료 깊이 | 현재 엔진 e5 / e8 세로벽 | 5.3 계열 비교 엔진 e5 / e8 세로벽 |
|---|---|---|
| 4 | 187 / 338 | 202 / 290 |
| 5 | -66 / 137 | -80 / 89 |

점수는 사용자 청록 관점이며 승률이 아니다. 강제 착수 뒤 깊이5는 강제 수를 포함하면 명목6수이고, 아래 일반 탐색 깊이5와 점수를 직접 비교하면 안 된다. 두 엔진은 탐색 코드 계보가 같으므로 독립적인 외부 증명으로 보지 않는다. 벽 후보 전부를 조사한 것도 아니며 e8 세로벽이 최선 또는 필승이라는 결론이 아니다.

같은 9수의 일반 탐색을 조기 종료 없이 최대15초·단일 코어로 재계산하면 깊이1~3 e5 → 깊이4 f7 가로벽 → 깊이5 e8 세로벽으로 바뀌었다. 깊이5 완료 시점은 약10초였다. 실제 저장 기보에서는 깊이4에서 약2초에 추천 안정 추정으로 종료했다. 현재 일반 탐색의 깊이4 추천이 당시와 다른 것은 현재 코드 변경·코어 수·공유 캐시 조건 차이의 한계다. 다만 얕은 합의가 더 깊은 결과를 보장하지 않는다는 반례는 확인된다.

## 좁힌 수정 범위

가변 분석에서 설치 벽3개 이상·양측 잔여 벽이 있는 위치는 깊이6 전에는 추천 안정만으로 자동 종료하지 않는다. 최초 추천 제공 시점과 최대15초 예산은 유지한다. 정확 종반 결과·기존 위험 안내·벽 재고 검사는 우선한다. 해당 상태는 대기 안내에서도 지금 착수 가능/추가 대기 실익 낮음으로 바꾸지 않는다. 깊이6은 정확성 보장이 아니라 얕은 안정 추정의 최소 보호 조건이다. 일부 판에서 계산이 최대 예산까지 이어지는 비용이 있다.

기본 평가 가중치·네이티브 엔진·최근 왕복 억제는 변경하지 않았다. 현재 바이너리 e463687b829d 및 비교 바이너리를 .external/game7-baseline에 로컬 보존했다. 기준 커밋은49c0c56이다. 과거 학습/평가 보고서나 사용자 기보는 수정하지 않았다.

## 재현과 검증

- 입력은 evaluation/fixtures/game7-record.json의 익명화된 기본 배치·55수다.
- scripts/compare-forced-game.mjs는 실제 수·합법 이동·방어 후보·공격벽 후보를 강제 적용하고 새 프로세스로 비교한다. 기준 바이너리는 로컬 .external/game7-baseline/pressure.exe, reference.exe 및 identity.json이 필요하다. 이미 보존된 기준을 덮어쓰지 않는다.
- depth4.json은 최초 후보 비교, budgeted-deeper.json은 유력 후보의 추가 계산이다. 후자는 요청 깊이에 못 미친 결과가 있으므로 같은 완료 깊이끼리만 비교한다.
- depth5-nine.json은9수 두 후보가 두 엔진 모두 깊이5를 완료한 결과다. root-nine.json은 일반 탐색 진행 기록이다.
- node scripts/check-detour-stop.mjs로 실제9수 배치의 깊이4/5 조기 종료 방지·대기 표시·깊이6 안정 종료·빈 보드·정확 종반·벽 재고 분기를 확인했다. 웹 빌드도 통과했다.
- 장시간 대전·승률 검증은 하지 않았다. 이번 수정은 얕은 추천을 확정하는 문제를 제한하며, 이 기보의 승리나 전체 실력 향상을 입증하지 않는다.

남은 검증은 후보 집중 비교가 전체 깊이 완료보다 빠르게 같은 대안을 찾는지, 이 보호 조건이 시간을 과도하게 쓰지 않는지, 그리고 기보6 왕복 회귀가 없는지다. 결과가 나오기 전에는 추가 평가 보정을 기본 엔진에 쌓지 않는다.
