# 기보11: 벽 실효성 평가와 제한된 도착 순서 탐색

## 적용

- 골인 안전 엔진의 중후반 잔여 벽 평가를 첫 수 보조 점수뿐 아니라 탐색 말단에도 적용한다. 벽 10개 이상 설치, 어느 한쪽 정적 거리10 이하인 범위에서 양쪽 자원이 남았더라도 검사한다.
- 현재 합법 공격벽의 최고 순 지연이0이면 공격용 보유 점수를 없애고,1이면 절반만 인정한다.2 이상이면 기존 보유 점수를 유지한다. 이 수치는 현재 배치의 선택적 휴리스틱이며 미래 준비벽이 무가치하다는 증명이 아니다.
- 상대에게 공격벽이 있고 그 위험한 앵커를 적은 자체 우회로 선제 차단할 수 있다면 별도 방어 가치를 최대120점 유지한다. 공격 가치가 없다고 벽의 가치를 무조건0으로 만들지 않는다.
- 최단 경로 DAG를 자르지 않는 벽은 거리 변화가0임을 이용해 두 번의 거리 계산을 생략한다. 회귀 검사에서 생략한 벽의 양쪽 거리가 실제로 변하지 않는지 확인한다.
- 내 벽이 상대보다 많으면 골인 보정을 생략하던 조건을 제거한다. 보조 위험 탐색도 목표가 가까우면1칸 지연부터 검토한다.
- 목표 거리가 가까운 불균형 자원 상황에서 탐색 말단의 공격→응수→두 번째 공격을3ply 더 선택적으로 검토한다. 범위는 한쪽 잔여2벽·다른 쪽3벽 이상, 거리 최소2 이하·최대4 이하로 제한한다. 추가로 확장하는 노드 예산은6개이며, 예산 소진 후에는 정적 평가를 사용한다. 총 호출 수가6이라는 뜻은 아니다.
- 추가 탐색에서는 말 이동, 상위 공격벽2개, 상위 상대 공격의 교차 방어벽을 비교한다. 합법성·현재 배치를 복구하고 취소/시간 한도를 따른다. 부분 탐색을 완전 승패 판정으로 표시하지 않으며, 기존 정확 종반 해법을 대체하지 않는다.
- 전면 탐색을 하던 기존 마지막1벽 종반까지 추가 계산을 적용하니 시간 내 깊이가 낮아져, 그 범위는 원래 탐색을 유지한다. 가변 모드의 최대2초는 변경하지 않았다.

- 22수: 양쪽 깊이5. 구버전 b9 가로벽→새버전 c5 이동.

## 한계
