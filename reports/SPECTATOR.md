# AI vs AI 관전 모드

2026년 10월 27일, 한국 시간. 기준 커밋: `4d97233`.

## 적용 범위

- 현재 Atlas 4와 보존된 Atlas 3를 양쪽에 독립적으로 지정.
- 양쪽 시간·코어 설정, 수 사이 간격, 시작·일시정지·한 수 진행.
- 대기 타이머와 진행 중 Worker를 취소하고 관전 세대 번호로 오래된 결과를 차단.
- 관전 중 직접 조작 방지, 마지막 이동·설치한 벽 강조, 선택한 수·예상 진행·노드 수 표시.
- 목표선 도착, 관전용 3회 반복·300수 제한의 종료 이유 표시.
- 기존 JSON 기보 호환, 설정을 포함하는 version 2 기보 저장. 불러오기와 새로고침 후 자동 대국은 일시정지.
- 일반 사용자 대전·양쪽 직접 조작·사용자 진영 상단 보기·이동 점·벽 미리보기 유지.

Atlas 3는 원본 보존 엔진을 단일 Worker에서 실행합니다. Atlas 4는 기존 분할 Worker 풀을 사용합니다. Worker가 두 엔진을 지연 로딩하므로 Vite Worker 출력을 ES 모듈 형식으로 설정했습니다. Rust 소스·WASM·학습 가중치는 변경하지 않았습니다.

## 검증

- Node 테스트 53개 통과, Vite 배포 빌드 성공.
- 관전 테스트: 한 수 진행, 자동 차례 교대, 계산 중 정지, 대기 중 정지, 취소 뒤 재시작, 잘못된 AI 수 차단, 승리 후 추가 실행 방지.
- 반복 배치는 벽 삽입 순서·벽 소유자 메타데이터를 제외한 실제 위치·자원·차례로 비교.
- 기존·신규 기보 복원과 잘못된 수 거부 확인. 저장 파일의 승패 메타데이터를 그대로 신뢰하지 않고 실제 기보로 상태를 계산.
- 실제 Worker 통합 테스트에서 Atlas 3 선택 및 1코어 제한 확인.

브라우저 검증에는 별도 포트 `5174`를 사용해 기본 포트 `5173`의 사용자 저장 상태와 분리했습니다. 브라우저 전용 타이머 호출에서 발견한 receiver 문제를 수정하고 자동 진행을 다시 확인했습니다.

브라우저에서 Atlas 4(2코어) 대 Atlas 3(1코어), 각 0.1초, 수 사이 간격 0으로 80수까지 자동 진행하고 분홍 승리 후 멈추는 것을 확인했습니다. 한 수 진행 후 정확히 1수에서 멈춤, 5초 계산 중 정지했을 때 수 미적용, 새 대국의 일시정지 상태, 새 탭의 자동 저장 복원을 확인했습니다. 화면에서 마지막 수 강조와 양쪽 설정을 시각적으로 확인했습니다.

실제 저장 버튼으로 다운로드한 `spectator-browser-game.json`을 보존했으며 80수 전체를 독립 규칙 엔진으로 재생해 승자와 설정을 확인했습니다. 파일 선택을 통한 UI 불러오기는 브라우저 확장 프로그램의 파일 URL 접근 설정 때문에 자동 검증하지 못했습니다. 복원 로직은 단위 테스트와 새 탭의 자동 저장 복원으로 확인했습니다. 이 검증을 위해 확장 프로그램 권한을 변경하지 않았습니다.

## 범위의 한계

이 모드는 엔진 대국 관전이며 신경망 학습 파이프라인을 실행하지 않습니다. 현재 한 판씩 관전하며, 선후공을 바꾸는 연속 대국·승패 통계·기보 전후 재생은 포함하지 않았습니다. 3회 반복·300수 제한은 관전 세션 종료를 위한 판정이고 공식 승리나 일반 플레이 규칙을 추가한 것이 아닙니다.
